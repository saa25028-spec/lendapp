GitHub & Firebase Hosting デプロイ手順ガイド

1 Google ログインを有効化（Firebase Console）

  1. Firebase Console を開く
  2. プロジェクト aaaa-c7d26 を選択
  3. 左メニュー Authentication > Sign-in method を開く
  4. Google を選択して「有効にする」をオンにして保存

2 Firestore データベースの権限設定

Firestore Consoleの「ルール」タブで、認証済みユーザーが読み書きできるように設定します。

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if request.auth != null;
    }
  }
}

3 GitHub リポジトリへ登録

作業フォルダでターミナルを開き、コマンドを実行します：

git init
git add index.html
git commit -m "Initial commit for equipment lending app"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/school-equipment.git
git push -u origin main

4 Firebase Hosting へデプロイ 

# Firebase CLIをインストール (未導入の場合)
npm install -g firebase-tools

# Firebaseへログイン
firebase login

# プロジェクトの初期化
firebase init hosting
# - Project: Use an existing project -> aaaa-c7d26
# - Public directory: . (または index.htmlのあるディレクトリ)
# - Configure as single-page app: Yes

# 公開デプロイ実行！
firebase deploy --only hosting
